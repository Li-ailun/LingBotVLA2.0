# 单任务1倍速可视化

运行基座模型的一个 clean 任务、一个 episode：

```bash
cd /home/lixiang/PROJECT/LingBotVLA2.0/baseline_base_model_adapter
bash run_clean_realtime_visualization.sh lift_pot 1
```

脚本只对本次进程设置 `ROBOTWIN_REALTIME_VISUALIZATION=1`，通过独立
`sitecustomize.py` 包装 SAPIEN `Scene.step()`。RoboTwin 的物理步长为
`1/250 s`，每个物理步完成后会等待到对应墙钟时刻，因此仿真不会快于现实。

如果推理或渲染超过预算，画面会慢于现实，不会通过后续加速追赶。模型推理时
仿真仍按当前同步评测入口暂停；这不是实机异步 RTC 模式。

关闭窗口或按 `Ctrl+C` 后，正常无可视化评估不受影响：

```bash
cd /home/lixiang/PROJECT/LingBotVLA2.0/baseline_base_model_adapter
bash run_clean_50x50.sh
```
