一，全参数微调上限高
但是（1）全参数微调5k步（6张显存60的显卡，训练5k步）和仅lora action expert成功率差别不算太大
但是（2）全参数微调5k步是学到了趋势，但是离完成还有距离，而lora action expert 里成功还很远，动作趋势学的也没有全量微调

二，rtc作用：
（1）对于lora来说，成功率提升不大，因为本来离成功就很远，虽然5k步也会抖动，但是同样的rtc让动作丝滑后，5k全量微调权重离完成任务更近了，lora只是更近了一点点
（2）对于5k全量微调，rtc比非rtc成功率提高将近十八点，原因是同样可以完成任务的趋势，由于rtc动作更稳，不会碰外物体，非rtc可能碰歪碰掉，如果可以稳稳抓住，同样可以成功。
