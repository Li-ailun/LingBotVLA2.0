## 1. 运行预检

预检不会启动仿真 episode：

```bash
cd /home/lixiang/PROJECT/LingBotVLA2.0/baseline_base_model_adapter
bash preflight.sh
```

## 2. 从头开始一轮正常 clean 评估

下面是全新评估命令，运行 50 个 clean 任务、每个任务 50 次：

```bash
cd /home/lixiang/PROJECT/LingBotVLA2.0/baseline_base_model_adapter
bash run_clean_50x50.sh
```

默认设置：

- 无实时可视化窗口
- 不保存视频
- BF16
- 单张 RTX 3090
- 单推理服务和单仿真 worker
- 每次执行都会创建一个新的正式 run 目录

> 当前已经存在一轮执行到 `lift_pot 19/50` 的正式 run。要保留这 19 次结果，
> 不要再次执行上面的全新评估命令，应使用第 5 节的续跑命令。

## 3. 中断正常评估

需要暂停时，在运行评估的终端按一次：

```text
Ctrl-C
```

启动器会停止推理服务和仿真 client，并释放端口及 GPU 显存。

断点只统计日志中已经出现完整 `Success rate:` 记录的 episode。中断时正在执行、
但尚未结束的 episode 不计入断点，续跑时会重新执行，因此不会把半个 episode
错误计入成功率。

不要删除原 run 目录；续跑需要读取其中的 `eval_logs/`。

## 4. 中断后进行实时可视化检查

正式评估停止后，可以单独启动一个带 SAPIEN 实时窗口的 clean episode：

```bash
cd /home/lixiang/PROJECT/LingBotVLA2.0/baseline_base_model_adapter

bash run_clean_50x50.sh \
  --visualize \
  --task lift_pot \
  --num-episodes 1
```

说明：

- 该命令只运行 `lift_pot` 的 1 个 episode。
- 它打开 SAPIEN 实时 viewer，但仍不保存视频。
- 可视化结果写入 `results/visualization_clean/`。
- 可视化 run 与正式 `zero_shot_clean` run 隔离，不计入正式 50×50 统计。
- episode 完成后程序会自动退出；需要提前结束时按一次 `Ctrl-C`。
- 可以把 `lift_pot` 替换为其他官方任务名。
- 可以修改 `--num-episodes`，但可视化只用于人工检查，通常运行 1 次即可。

## 5. 停止可视化后，继续原正式 clean 评估

当前正式 run 使用下面的续跑命令：

```bash
cd /home/lixiang/PROJECT/LingBotVLA2.0/baseline_base_model_adapter

bash run_clean_50x50.sh \
  --resume-run \
  /home/lixiang/PROJECT/LingBotVLA2.0/baseline_base_model_adapter/results/zero_shot_clean/baseline_base_model_adapter_0k_demo_clean_20260930_143902
```

续跑脚本会自动读取该 run 中最后一个包含完整 `Success rate:` 的任务日志。对于当前
断点，它将：

```text
恢复任务：lift_pot
已有正式结果：0/19
从 seed 100046 继续
补足 lift_pot 到 50 次
然后继续剩余 49 个 clean 任务
继续写入原正式 run 目录
```

如果续跑后再次中断，仍然执行同一条 `--resume-run` 命令。脚本会重新读取最新完整
episode，而不是固定从 19 次开始。

> 中断后不要直接执行 `bash run_clean_50x50.sh`。该命令会创建一轮新的评估，
> 不会延续原 run。恢复旧进度必须提供 `--resume-run <原run目录>`。

## 6. clean 完成后运行 randomized 评估

clean 50×50 全部结束后，再顺序运行 randomized 50×50：

```bash
cd /home/lixiang/PROJECT/LingBotVLA2.0/baseline_base_model_adapter
bash run_randomized_50x50.sh
```

clean 和 randomized 不要同时运行；单张 RTX 3090 无法安全并行承载两套模型服务和
仿真进程。

如果 randomized 中途停止，其续跑方式相同，只需把 `--resume-run` 指向对应的
`results/zero_shot_randomized/<run目录>`：

```bash
cd /home/lixiang/PROJECT/LingBotVLA2.0/baseline_base_model_adapter

bash run_randomized_50x50.sh \
  --resume-run \
  /home/lixiang/PROJECT/LingBotVLA2.0/baseline_base_model_adapter/results/zero_shot_randomized/<实际run目录>
```

## 7. 结果目录

```text

baseline_base_model_adapter/results/visualization_clean/   # 独立可视化检查
```

```text

stats.txt        # 全部任务结束后生成的汇总
```
