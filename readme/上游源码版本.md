# 上游源码版本记录

本项目根目录作为唯一 Git 仓库。为保留当前全部源码与本地修改，同时解除与官网仓库的直接 Git 连接，两个上游仓库的 `.git` 元数据在本地改名为 `.git.upstream-backup`，并由根目录 `.gitignore` 排除，不会上传。

- 上游地址：`https://github.com/Robbyant/lingbot-vla-v2.git`

## RoboTwin

- 基准提交：`13c3c47ff4312dd62484bcd51be034af55c062d1`
- 当前目录包含本项目为 LingBot-VLA、RTC、视频录制及断点续评所做的本地适配。

## 恢复说明

如需临时恢复某个目录的独立上游 Git 历史，应先确认根仓库没有正在执行的 Git 操作，再将对应目录中的 `.git.upstream-backup` 改回 `.git`。恢复后，该目录会重新成为嵌套 Git 仓库。

模型权重、数据集、RoboTwin 下载资产、评估结果、视频和本机环境均不纳入 Git；它们应按项目文档中的下载或生成步骤在目标机器上恢复。
