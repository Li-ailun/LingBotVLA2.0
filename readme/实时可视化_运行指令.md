# 推荐运行指令

```bash
cd /home/lixiang/PROJECT/LingBotVLA2.0/baseline_base_model_adapter
bash run_clean_realtime_live.sh lift_pot 1
```

参数一是任务名，参数二是 episode 数量。该入口以250 Hz限制SAPIEN物理时间，
并以最高30 FPS刷新Viewer。它只用于观察，不写入或续接正式评估进度。

退出时关闭SAPIEN窗口，然后在终端按 `Ctrl+C`；正常正式评估仍使用：

```bash
bash run_clean_50x50.sh
```
